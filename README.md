# LocaHost Website

Website mẫu được dựng theo ảnh thiết kế Figma người dùng cung cấp.

## Chạy trên máy tính
1. Giải nén thư mục.
2. Mở thư mục `locahost-website` bằng Visual Studio Code.
3. Mở `index.html` bằng trình duyệt, hoặc cài Live Server trong VS Code rồi chọn **Open with Live Server**.

## Đưa lên GitHub Pages
1. Tạo repository mới tên `locahost-website`, chọn Public.
2. Upload 3 file `index.html`, `style.css`, `script.js` và commit.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, nhấn Save.
6. Chờ GitHub tạo website. Đường dẫn thường có dạng `https://TEN-TAI-KHOAN.github.io/locahost-website/`.

## Lưu ý
- Nội dung và dữ liệu chỗ nghỉ hiện là dữ liệu minh họa để dựng giao diện.
- Ảnh và font chữ được tải từ các dịch vụ trực tuyến, nên cần Internet để hiển thị đầy đủ.
- Chức năng đặt phòng, đăng nhập và đăng ký hiện là giao diện demo, chưa kết nối máy chủ hay cơ sở dữ liệu.
